# Features

## Available

- Short and full hardcoded outreach templates shown together.
- Groq-generated third draft using editable plain-text resume and optional job description.
- Server-only Groq key, configurable model, timeout, input validation, safe error messages.
- Message/email channels; editable email subject and Open email action (default mail app).
- Role-specific referral/recruiter and generic employee/HR audiences.
- Five resume highlight choices and updated resume link, email, title, and verified achievements.
- Editable outputs, copy actions, and last-20 message history.
- Company draft restore, company autocomplete, LinkedIn people search, connection notes.
- Mobile layout and saved resume-link/connection-note settings.

Application tracking and CSV exports have been removed.

## Useful next additions

1. Import a job description from a careers URL to avoid manual copying.
2. Follow-up generator that uses the actual previous message/reply.
3. Gmail draft integration to support resume attachments and richer formatting.
4. Multiple resume profiles for backend, platform, and AI roles.
